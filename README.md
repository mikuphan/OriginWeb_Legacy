📌 About this repository

This repository contains legacy versions (v1.2 – v1.4) of OriginOS WEB, originally created by Quandz24.

These versions are archived and preserved because:

Original links are no longer working

Some forks removed old versions

Legacy builds provide a lighter, smoother experience compared to newer releases


⚠️ Note:

This repository is NOT an official project of Quandz24

This is an archive / preservation repo



---

✨ Why Legacy versions?

Older UI style (classic OriginOS look)

Faster load time

Less JavaScript overhead

Works better on low-end devices

📌 Введение

В этом репозитории хранятся старые версии (v1.2 – v1.4) OriginOS WEB, оригинального проекта, созданного Quandz24.

Эти версии были извлечены и заархивированы по следующим причинам:

Оригинальная ссылка больше не работает.

Многие форки удалили старую версию.

Устаревшая версия легче и работает плавнее, чем новая.

⚠️ Примечание:

Этот репозиторий НЕ является официальной версией от Quandz24.

Это архивный/сохраняющий репозиторий.

---

✨ Почему стоит использовать устаревшую версию?

Оригинальный интерфейс OriginOS

Более быстрая загрузка

Меньше JavaScript → более плавная работа

Подходит для устройств с низкими характеристиками или для ностальгических впечатлений
